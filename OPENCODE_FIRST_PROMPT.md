# Primer prompt para OpenCode

Copia este mensaje en OpenCode después de colocar los archivos de
documentación en la raíz del proyecto.

------------------------------------------------------------------------

Lee y analiza las instrucciones del proyecto en `AGENTS.md` y toda la
documentación de `docs/`:

-   `docs/SRS.md`
-   `docs/ARCHITECTURE.md`
-   `docs/DATABASE.md`
-   `docs/DEVELOPMENT_PLAN.md`

El proyecto se llama **StudyTask**. Es un gestor sencillo de tareas
académicas desarrollado con Node.js, Express, PostgreSQL, Sequelize,
EJS, Bootstrap y JWT en cookie HttpOnly.

**IMPORTANTE: todavía no quiero que programes ni inicialices el
proyecto.**

En esta primera tarea debes:

1.  Leer todos los documentos.
2.  Resumir el objetivo y alcance de StudyTask.
3.  Identificar los requisitos académicos obligatorios que cubre.
4.  Revisar si existen contradicciones, ambigüedades o decisiones
    técnicas pendientes.
5.  Comprobar si la estructura propuesta cumple la arquitectura MVC
    exigida.
6.  Señalar riesgos de seguridad o dependencias que deban verificarse
    antes de implementar.
7.  Proponer correcciones documentales concretas, sin aplicarlas
    todavía.
8.  Confirmar que entiendes que el registro público solo crea usuarios
    `user`, y que las tareas se aíslan por propietario.

No crees archivos de código, no instales dependencias, no ejecutes
comandos de inicialización y no modifiques los documentos.

Termina con: - Un resumen de comprensión. - Una lista de posibles
problemas documentales. - Una lista de decisiones que requieren
confirmación. - Una confirmación explícita de que no has comenzado a
programar.

Espera mi autorización antes de iniciar la Fase 1 del plan de
desarrollo.
